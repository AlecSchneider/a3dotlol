2. Deploy this committed backend to Convex `vivid-leopard-322`, team

3. Merge this PR into `main` and verify the resulting Vercel production

   cleanup. Do not assume a Vercel website build deploys Convex: the current

perform a destructive sweep of historical rate-limiter records. Rollback
must account for already scheduled `lib/rateLimits:expireEmailQuota` jobs;
retain that internal function until pending jobs drain, rather than blindly
reverting the backend bundle.
